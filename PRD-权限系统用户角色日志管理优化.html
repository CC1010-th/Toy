权限系统用户、角色与日志管理需求说明

1. 需求背景

本需求面向当前权限系统后台的用户管理、角色管理和日志管理报表页面，用于提升角色关联用户的查询效率，以及日志查询、查看和审计效率。

2. 需求范围

本需求包含：

  • 用户管理按所属角色筛选用户。
  • 角色管理通过使用人数联动查看对应用户。
  • 日志管理支持多条件查询、完整操作对象展示和操作记录详情查看。

以下内容不在需求范围内：

  • 商户管理、部门管理、资源管理和数据资源页面。
  • 用户或角色的新增、编辑、删除、状态变更、权限配置、密钥修改和密码重置逻辑。
  • 用户与角色数据口径、账号权限模型和服务端权限规则。
  • 日志采集链路、存储周期、导出能力和服务端审计策略。

3. 用户管理

3.1 所属角色筛选

  • 查询区按用户账号、商户名称、所属角色、创建人、状态和创建日期进行筛选。
  • “所属角色”位于“商户名称”之后。
  • “所属角色”为单选下拉框，默认显示“请选择”，表示不限制所属角色。
  • 下拉选项展示当前可查询的角色名称。
  • 点击查询后，用户列表展示符合全部已填写条件的用户。
  • 点击重置后清空全部查询条件，并展示默认用户列表。
  • 从角色管理的使用人数进入时，“所属角色”自动选中对应角色，用户列表直接展示该角色的用户，无需再次点击查询。

4. 角色管理

4.1 使用人数联动

  • 角色列表展示每个角色的使用人数。
  • 使用人数为可点击数字，数值为 0 时仍可点击。
  • 点击使用人数后进入用户管理页面。
  • 用户管理的“所属角色”自动选中对应角色。
  • 用户列表自动展示该角色对应的用户。
  • 对应角色没有用户时，列表展示空状态。

5. 日志管理

5.1 查询区

查询区包含以下四个查询维度：

  1. 用户账号
  2. 操作类型
  3. 关键词
  4. 操作时间

各查询条件按“且”关系组合；未填写或未选择的条件不参与过滤。

5.1.1 操作类型

  • 默认值为“全部”。
  • 可选项包括查询、导出、新增、修改、删除、审核和登录。
  • 选择具体类型后，仅返回该操作类型的日志记录。

5.1.2 操作时间

  • 使用开始时间和结束时间两个日期时间控件。
  • 时间选择精确到秒。
  • 仅填写开始时间时，返回操作时间大于或等于开始时间的记录。
  • 仅填写结束时间时，返回操作时间小于或等于结束时间的记录。
  • 同时填写开始时间和结束时间时，返回闭区间内的日志记录。
  • 开始时间不得晚于结束时间；不符合要求时阻止查询并提示用户。

5.2 关键词检索

  • 关键词检索范围为“操作对象”和“操作记录”。
  • 关键词命中任一字段即视为匹配成功。
  • 关键词与用户账号、操作类型和操作时间按“且”关系组合。
  • 关键词为空时不限制操作对象和操作记录。

5.3 操作对象

  • 操作对象展示日志记录中的完整原始路径。
  • 完整路径作为一个字段展示，不进行菜单层级解析或重组。
  • 路径层级为空时不影响该条日志的正常展示。

5.4 操作记录

  • 操作记录展示日志原始参数中的非敏感内容。
  • 密码、Token、Secret、API Key、Authorization、手机号、邮箱和证件号等敏感信息必须脱敏。
  • 表格中的操作记录采用单行缩略展示。
  • 点击操作记录后，以全站通用的居中弹窗展示脱敏后的完整内容。
  • 弹窗仅展示操作记录，不展示用户账号、操作时间、操作类型和操作对象等其他日志字段。
  • JSON 内容格式化展示；非 JSON 内容按原文展示。
  • 弹窗为只读状态，支持复制完整操作记录。
  • JSON 的复制内容为格式化后的完整 JSON；非 JSON 内容按原文复制。
  • 复制内容与弹窗展示内容一致，且不得包含敏感信息。
  • 复制成功后显示轻提示。
  • 支持通过关闭按钮、点击遮罩或按 Esc 键关闭弹窗。

5.5 日志列表

日志列表按以下顺序展示字段：

  1. 序号
  2. 用户账号
  3. 操作时间
  4. 操作类型
  5. 操作对象
  6. 操作记录
  7. 登录 IP

6. 验收标准

6.1 用户管理

  1. 查询区的“所属角色”位于“商户名称”之后，默认显示“请选择”。
  2. 所属角色下拉框可展开并选择单个角色。
  3. 查询后，列表仅展示符合全部已填写条件的用户。
  4. 所选角色没有用户时，列表展示空状态。
  5. 点击重置后清空全部查询条件，并展示默认用户列表。

6.2 角色管理

  1. 每一行使用人数均可点击，包括数值 0。
  2. 点击使用人数后进入用户管理页面。
  3. 用户管理页面标题和侧栏选中状态正确。
  4. “所属角色”自动选中对应角色，无需再次点击查询。
  5. 用户列表仅展示对应角色的用户；使用人数为 0 时展示空状态。

6.3 日志管理

  1. 查询区支持用户账号、操作类型、关键词和操作时间四个维度组合查询。
  2. 操作类型默认显示“全部”，并可选择查询、导出、新增、修改、删除、审核和登录。
  3. 关键词命中操作对象或操作记录任一字段时返回该记录。
  4. 关键词与其他查询条件同时使用时，各条件按“且”关系生效。
  5. 操作时间支持开始时间和结束时间，并可选择到秒。
  6. 单独填写开始时间或结束时间时，单边时间条件正确生效；同时填写时按闭区间筛选。
  7. 开始时间晚于结束时间时，系统阻止查询并给出明确提示。
  8. 日志列表按规定顺序展示 7 个字段。
  9. 操作对象展示完整原始路径，且路径层级为空时页面展示正常。
  10. 操作记录在表格中单行缩略展示，点击后打开居中弹窗。
  11. 弹窗仅展示脱敏后的完整操作记录，不展示其他日志字段。
  12. JSON 操作记录格式化展示并可复制格式化后的完整 JSON。
  13. 非 JSON 操作记录按原文展示和复制。
  14. 详情弹窗为只读状态，可通过关闭按钮、遮罩或 Esc 正常关闭。
  15. 复制成功后显示轻提示，复制内容与展示内容一致且不包含敏感信息。
