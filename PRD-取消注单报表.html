取消注单报表 PRD V1.0

旧禅道 #4825 · Confluence 163088852 · 2026-11-06

一、需求背景

新增取消注单报表，记录取消赛事、注单及操作人员数据，支持风控事后追踪和分析。

二、数据范围

  1. 数据来源：注单管理 / 取消冻结注单。
  2. 仅统计单关注单，且注单状态为“注单无效”。
  3. 数据每日更新，保存时间与体育报表 / 操盘统计一致。

三、筛选条件

体育报表 > 风控统计 > 取消注单报表

筛选项依次为：开赛日期、商户分类、商户编码、联赛等级、取消原因、赛种、玩法、投注阶段、联赛名称、赛事名称、赛事 ID、操作人。

  1. 开赛日期默认近一周。
  2. 取消原因复用操盘后台“取消注单统计”组件，默认全选。
  3. 玩法复用操盘后台“取消注单统计”组件。
  4. 操作人为下拉选单，候选项为报表中已有记录的操作人。
  5. 其余共用筛选项复用 UAT 报表后台同字段交互；需求与源表冲突时以本需求为准。

四、汇总与列表

  1. 汇总指标：总取消赛事、总取消笔数、总取消人数、总投注金额、总挽回损失。
  2. 列表按“开赛日期 → 联赛 → 赛事”三级展示。
  3. 联赛展示联赛等级；赛事展示短 ID，并支持复制长 ID。
  4. 列表字段：赛种、开赛日期、取消笔数、取消人数、投注金额、挽回损失、操作人、操作时间。
  5. 取消人数按用户去重；多个操作人使用 / 分隔；操作时间取最后一次操作时间。
  6. 所有数值及日期字段支持排序。

五、取消批次明细

  1. 赛事下按取消原因统计取消批次。
  2. 批次按“第 N 次”展示，并支持展开为批次内“第 N-M 笔”记录。
  3. 字段：取消批次、取消原因、取消玩法、取消笔数、取消人数、投注金额、挽回损失、取消时间段、操作人、操作时间。
  4. 多个取消玩法或操作人使用 / 分隔。
  5. 取消时间段取该取消原因第一笔至最后一笔取消注单时间；操作时间取最后一次操作时间。

六、挽回损失与金额

  1. 挽回损失 = 投注金额 × 港赔赔率。
  2. 仅“疑似协议赛”“进球点注单”“异常投注”计算，其他原因显示 -。
  3. 同一联赛或赛事存在多种取消原因时，加总其中有数值的挽回损失。
  4. 投注金额及挽回损失使用 ¥ 标识并保留两位小数。

七、导出、脱敏与权限

  1. 导出字段：赛种、联赛、赛事名称、开赛日期、取消批次、取消原因、取消玩法、取消笔数、取消人数、投注金额、取消时间段、挽回损失、操作人、操作时间。
  2. 页面名称、筛选项、列表及导出字段执行现行脱敏规则。
  3. 分别配置页面查看和导出权限。

八、验收标准

  1. 风控统计下可访问取消注单报表。
  2. 数据范围、筛选项、汇总指标、列表层级、批次明细及导出字段与本 PRD 一致。
  3. 金额显示 ¥ 并保留两位小数；不适用挽回损失的取消原因显示 -。
  4. 脱敏、排序及页面查看/导出权限生效。

九、待确认事项

以下两项未纳入当前验收口径，确认后另行更新：

  1. 港赔赔率取下注时、取消时还是其他业务快照。
  2. 总计、开赛日期、联赛、赛事、取消原因及批次层级的取消人数去重边界。
