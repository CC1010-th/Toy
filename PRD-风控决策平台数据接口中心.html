1 产品目标与文档基线

数据接口中心是风控决策平台中负责数据接入与运行保障的部分，围绕现有数据接入和计算链路，提供来源资料登记、共享任务目录、同步监控、作业监控、质量检查和告警定位。运营以列表和弹窗完成日常操作，技术人员维护连接、执行器和可补算能力，平台负责权限与审计。任务编排、开发部署和实际数据写入继续由既有 Flink、Java 程序与海豚调度承担。

本 PRD 以 V9.9 独立 HTML 原型为当前交互基线。V9.9 在 V9.8 基础上补齐人工新增对象的删除，并为来源表增加字段维护与导入。相对 V9.0，页面并入风控决策平台的统一菜单，同步监控按首期范围收窄，作业接入增加“用途”，告警按对象合并并去掉级别显示。用于产品评审、研发拆解和测试验收；未确认的阈值、容量和业务口径在第 17 章集中列示。

2 范围、规则与术语

  • 大部分来源表没有同步映射是正常情况。来源表资料可以独立保存，未关联不等于同步失败。
  • Flink 任务登记一次，进入共享目录；一个任务可供多张来源表选择。每张来源表最多保留一条当前任务关联和一个目标表。
  • 编辑映射与更换任务合并。用户在同一弹窗修改任务、目标表与说明；后台识别改动并保留旧关联及观测快照。
  • 人工任务集中在 Flink 任务页面新增、校验、编辑和删除；来源表页面不重复采集任务身份。
  • 全页面不采集或展示负责人字段。
  • 人工操作记录统一进入权限管理的操作记录；本模块不增加操作记录页面。采集诊断、执行日志与历史关联属于业务查询资料。
  • 人工新增的对象都可以删除：数据源、来源表、字段、人工登记的 Flink 任务、人工登记的 Java 执行器、连接和检查任务。仍被引用时不能删除，弹窗列出引用对象；删除只去掉本平台登记资料，不影响外部系统（GEN13）。
  • 数据源、来源表和字段是变量中心“因子新增 / 编辑”口径勾选的数据基础：来源表、字段、分子分母、归窗字段、过滤条件和去重键都从本平台登记的资料中选择；被因子引用的来源表和字段不能删除（5.4）。
  • 来源表可登记字段，支持在列表的“字段”抽屉中逐个维护，也支持按模板批量导入来源表和字段（TBL03、TBL04）。
  • 数据字典由其他负责人设计，不在本文范围；菜单中“数据管理 › 数据字典”只保留入口位置，原型显示占位页。
  • 告警中心属于监控中心模块，保留前往按钮。点击时校验目标权限，无权限时提示并停留；有权限时定位对应记录。同一规则、同一对象的异常合并为一条告警，跑批按作业、同步按 Flink 任务合并；页面不显示告警级别。
  • 同步监控首期只展示同步链路与 Flink 运行状态。读取滞后、导入耗时、写入结果、快照时效、观测状态和同步详情列入二期，前提见 8.3。
  • 作业接入中的“用途”把作业分为业务加工和质量检查：作业监控看程序有没有按时跑完，质量检查看数据对不对；一次质量执行器的运行同时出现在两处，各看各的结论。
  • 作业监控合并原作业和跑批监控；监控选择与补算能力设置放在作业接入。补算从作业监控就地发起，不增加独立菜单。
  • 首期没有文件到档核对、参数表版本、包管理、任意 SQL 编辑、JAR 上传、DAG 编排、消费位点重置或面向运营的任务停止功能。数据模型校准统一按质量检查执行，不代表统计模型自动训练。

2.1 术语与命名约定

同一概念全平台只用一个词；页面、告警、接口和测试用例都按下表取词。V8.9 中“同步配置 N 条”“已关联映射”“读取延迟 / 写入延迟”等说法不再使用；V9.x 起“数据接口中心”不再作为菜单分组名。

术语定义页面用语与禁用说法
来源表在数据源下登记的物理表，以环境、数据源、表名唯一。不等于“同步对象”；未关联是正常状态
映射（关联）一张来源表与一个共享 Flink 任务、一个目标连接下的目标表之间的当前对应关系。每表最多一条当前映射，其余为历史。状态只用“已关联 / 未关联 / 旧版多关联待确认”；操作用“关联映射、查看关联、取消关联”；查看关联弹窗中的“编辑”即编辑映射
共享任务Flink 任务页面中的一条登记，以环境、集群、Job ID 唯一，可被多张来源表引用。“登记名称”是平台展示名；“运行任务名称”来自集群
校验状态待验证、已验证、校验失败，表示登记身份能否在集群查到。与运行状态无关，不写成“任务失败”
运行状态Flink 返回的 RUNNING、RESTARTING、FAILED 等原值。只展示外部原值，不翻译为“正常”
观测状态（二期）平台按运行状态、指标、写入回执与快照时效推导的正常、延迟、失败、无法判断。首期页面不出现；不由运行状态单独决定
用途作业接入对作业的分类：业务加工、质量检查。决定能否开放补算、能否被检查任务选用、作业监控默认是否显示。页面只用这两个词；不再用“作业类别”“数据质量”等说法
已备案检查范围用途为质量检查的执行器声明可检查的数据范围，检查任务只能从中选择一项。被检查任务引用后不可修改
字段来源表下登记的列：字段名、业务名称、字段类型、长度 / 精度、主键、允许为空、说明。同一来源表内字段名唯一（不区分大小写）。只是平台登记资料，不读写源库表结构
删除从本平台移除登记资料并写操作记录；历史执行、报告和关联历史保留。不等于停用外部任务或删除外部数据
因子引用变量中心因子口径中对来源表、字段的引用，按来源表 ID 与字段 ID 记录，同时保存名称快照。不按表名、字段名匹配
告警对象告警合并的单位，见 ALT02。跑批为作业，同步为 Flink 任务，质量为检查任务与范围
作业在作业接入登记并可纳入监控的海豚工作流或 Java 执行器。全平台使用作业接入中的“显示名称”；海豚定义名、程序编码作为副标题
检查任务质量检查页面中的配置对象，引用一个作业和一个已备案检查范围。与“作业”不同名，如“基础数据综合检查”引用“基础数据质量执行器”
同步方式取值Flink CDC、RocketMQ → Flink、Kafka → Flink、Flink。统一用箭头，不再出现“RocketMQ + Flink”
执行方式取值海豚工作流、Java程序。筛选项与列表列一致
时间页面统一 YYYY-MM-DD HH:mm:ss，按业务时区展示（首期 Asia/Shanghai，UTC+8）；存储与接口使用 UTC。不混用“2026/11/24”与“2026-11-24”

4 角色与通用交互

  • GEN01 采用分字段筛选、查询、重置、分页和就地弹窗。来源表名称与业务名称分列，同步任务与目标表分列。所有列表页的分页规则见 GEN12。
  • GEN02 来源表可用紧凑上下三角排序；排序不改变列宽，支持鼠标拖动调宽，页面自适应避免水平滚动。排序必须有稳定的次序规则。
  • GEN03 保存前校验必填、格式、重复、版本和权限；失败保留输入并展示可理解的原因。取消弹窗不产生写入。
  • GEN04 未关联、待验证、未采集、过期、无法判断、真实失败分别表达；缺失值不能自动变成零。读接口失败不等于外部任务失败。
  • GEN05 详情和编辑返回原列表、原筛选和原页码。告警定位后突出显示对象，由用户主动打开详情；不连续自动弹多层窗口。
  • GEN06 时间展示统一为 YYYY-MM-DD HH:mm:ss（业务时区），日期筛选按业务日期比较；所有列表的日期筛选、时间排序对全部记录一致生效。
  • GEN07 同一对象全平台同名：作业以作业接入中的显示名称出现在告警标题、作业监控、作业接入弹窗标题和质量检查“执行程序”列；外部定义名作为副标题。
  • GEN08 写操作按权限显示：无写权限不显示新增、编辑、执行类按钮；只读打开的表单禁用输入并移除保存。按钮隐藏不能替代后端鉴权。
  • GEN09 列表版式：每列只放一项信息，不在单元格内用第二行放编号、范围、次数或说明。操作列一般最多 3 个直接按钮，不使用“更多”下拉；对象名称本身是详情入口，技术关联、运行趋势等次要操作放在详情或记录弹窗底部。例外：来源表每行为“关联映射 / 查看关联、字段、编辑、删除”4 个按钮，1366px 宽度下不换行（是否接受见 DEC23）。
  • GEN10 字号与控件规格：页面标题 20px；弹窗与卡片标题 15px；侧栏菜单 14px；正文、表格正文与表格内链接、表单控件、按钮、筛选下拉及其选中值、弹窗字段与取值统一 13px；提示文字与状态标签 12px。输入框、下拉框以及页面和弹窗的操作按钮高 32px；翻页按钮和每页行数下拉高 28px，并与左侧说明文字上下居中。表头高 40px、数据行高 48px。编号、Job ID、编码用等宽字体，时间与数字用等宽数字；状态、时间、编号不换行，结论说明类列可换行。状态标签全平台同一规格（含来源表“已关联 / 未关联”），颜色按语义区分。1366px 及以上宽度的列表不出现横向滚动；过长的 Job ID、定义名称和服务标识截断显示，悬停看全文。
